# 飞书云文档「文档」模块复刻 — 设计规范与开发对照文档 v2

> 本文档是开发的**唯一验收依据**。目标：UI 与功能与飞书云文档（docx 新版文档）一致。
> v2 修订（2026-09-06）：依据官方帮助中心与实机观察重写交互规范（斜杠菜单分组、标题渐进显示、四种工具栏体系、快捷键对齐），并落地 P0 交互对齐的验收标准。差距分析见 `docs/feishu-gap-analysis-and-optimization-plan.md`。
> 说明：本项目为学习/研究用途的高保真复刻。图标等视觉资产为自行绘制的近似 SVG，不复制飞书任何专有素材。

## 3. 编辑器内容模型（Block，对齐飞书 docx block_type）

飞书以 Block 为最小单元，官方枚举 40+ 种。本期实现：

| 块 | 类型标识 | 飞书唤起 | 状态 |
|---|---|---|---|
| 页面/标题区 | page | — | ✅ |
| 文本 | text(2) | 直接输入 | ✅ |
| 标题 1~9 | heading1~9(3-11) | `#`~`#########`、⌘⌥1~9、菜单渐进 | ✅ |
| 无序/有序列表 | bullet(12)/ordered(13) | `-`、`1.`、⌘⇧8/7 | ✅ |
| 任务 | todo(17)/task(35) | `[]`、⌘⌥T、/任务 | ✅ |
| 引用 | quote(15) | `>`、⌘⇧> | ✅ |
| 分割线 | divider(22) | `---`、⌘⌥S | ✅ |
| 代码块 | code(14) | ``` 、⌘⌥C | ✅（语言下拉+复制；语法高亮 P1） |
| 高亮块 | callout(19) | /高亮块 | ✅（emoji+底色） |
| 图片 | image(27) | /图片、粘贴 | ✅（本地上传；缩放/题注 P1） |
| 表格 | table(31) | /表格 | ✅（列宽拖拽已启用；单元格增强 P1） |
| 公式(块/行内 KaTeX) | equation(16) | /公式、$...$ | ✅ |

| 日期提醒 | dateChip | /日期提醒、// | ✅ |
| 模版 | — | /模版 | ✅（会议纪要/周报/PRD） |
| 同步块/视频或文件/群名片/云文档/任务清单/投票/信息收集/日程/会议议程 | — | / 菜单 | 🔶 演示占位卡（mockBlock），逐版替换 |

### 3.1 行内样式

加粗⌘B、斜体⌘I、下划线⌘U、删除线⌘⇧X、行内代码（Mac Ctrl+⌘C / Win Ctrl+Shift+C）、链接⌘K、字体颜色+背景色（合并面板，9 色文字 + 7 色背景 + 恢复默认）。

### 3.2 Markdown 即时转换

`#`~`#########` 标题、`-`/`1.` 列表、`[]` 待办（列表内仅转换当前行）、`>` 引用、``` 代码块、`---` 分割线（嵌套内提升到顶层）、`**粗**` `*斜*` `~~删~~` `` `码` ``（中文后闭合标记同样生效）。

## 4. 核心交互规范（v2 重点）

### 4.1 标题渐进显示（飞书"防滥用层级"）

- 规则：**可见级别 = 1..min(9, max(3, 文档已使用最深层级 + 1))**，从文档内容实时推导，删标题即回缩。
- 新文档只出现 一/二/三级标题；用了 H3 → H4 出现；依此类推至 H9。
- 生效位置：斜杠菜单「基础」组、顶部工具栏样式下拉、块把手/浮条的 T 菜单主列表。
- T 菜单固定另含「**其他标题**」子菜单 = 未直接展示的级别（N+1..9）。
- Markdown 输入与 ⌘⌥1~9 快捷键不受限制（1~9 全量可用）。

### 4.2 斜杠菜单（/ 快速插入）

- 触发：**行首或空格后**输入 `/`（其余位置不触发）；继续输入模糊过滤：中文名 / 英文词 / 拼音缩写（官方缩写表：/h1、/yxlb、/wxlb、/yy、/fgx、/lj、/rw、/tp、/bg、/fl、/glk、/gs、/dmk、/rq…）。
- 弹层 ~348px 单列，分组标题吸顶；条目 = 36px 图标底 + 名称 + 右侧 12px 灰字说明。
- 分组与条目（顺序对齐实机）：
  - **AI帮我写**（置顶特殊条目，渐变星光图标）→ 打开 AI 面板
  - **基础**：文本、一级~三级标题（+渐进解锁的更深层级）、有序列表、无序列表、代码块、引用、分割线、链接
  - **常用**：任务、图片、视频或文件、表格、分栏、高亮块、同步块、公式、模版
  - **按钮**：打开超链接、创建副本、关注文档更新
  - **团队协作**：人员、群名片、云文档、任务清单、投票、日期提醒、信息收集、日程、会议议程
- 键盘：↑↓ 循环、Enter/Tab 插入、Esc 删除 `/query` 并关闭。
- 「AI帮我写」面板：接入用户自备模型（OpenAI Chat Completions 兼容；Base URL / API Key / 模型名 / temperature 存 localStorage，页面直连、需 CORS）；快捷指令 帮我写/续写/润色/翻译/总结；流式输出；插入到文档/复制/重新生成/停止。

### 4.3 块把手（+ 工具栏 / ⋮⋮ 工具栏，v2.1 对齐最新版）

- 悬停**任意行**，行首直接浮现按钮对（所见即点，无需二次悬停展开）：
  - 内容行 → **[T 文本样式][⋮⋮ 六点把手]**：点击 T 打开文本样式菜单（§4.1 条目 + 缩进/对齐 + 在下方添加）；点击 ⋮⋮ 打开操作菜单（剪切/复制/上移/下移/删除）；
  - 空白行 → **[+ 插入][T 文本样式][⋮⋮]**；+ 就地打开插入菜单（基础+常用 组）。
- **按住 ⋮⋮ 拖拽**移动块：拖拽中出现蓝色插入指示线（--brand 2px），跨块重排。
- 移动当前块快捷键：Win Alt+Shift+↑↓ / Mac ⌘⇧↑↓。

### 4.3.1 大纲（目录）

- 位于**正文左侧**（对齐飞书新版），240px，可通过面板头部「«」收起；收起后左侧出现竖向「大纲」入口，点击恢复。

### 4.4 浮动工具栏

- 选中非空文字时出现在选区上方（空间不足移到下方）：
  **[✦ 问问AI][解释] | T▾ 文本样式 | B I U S 行内代码 | 颜色▾ | 链接 | 缩进− 缩进+ | 评论**
- 颜色面板 = 文字颜色 9 色 + 背景颜色 7 色 + 恢复默认。

### 4.4.1 「问问AI」右侧对话栏（对齐飞书"问问豆包"并增强）

- 入口：浮动工具栏「问问AI」「解释」、斜杠菜单「AI帮我写」（快捷指令模式）、一键排版未配置引导。
- 右侧停靠栏（380px），多轮流式对话；上下文自动取打开时的选区/所在段，可清除。
- 快捷指令：帮我写 / 续写 / 润色 / 翻译 / 总结。
- **每条回答可**：插入到下方 / 替代当前文本（选区优先）/ 作为引用插入 / 作为代码框插入 / 复制 / 重新生成。
- 模型配置同 §4.2（用户自备 OpenAI 兼容服务）。

### 4.4.2 一键排版（超出飞书原生的增强能力）

- 顶部工具栏右侧「✦ 一键排版」：LLM 分析全文顶层块，输出标题层级方案（0=正文，1~3=标题）。
- **先预览后执行**：弹窗展示识别出的标题结构树（层级缩进 + 原级别 + 变更统计），用户确认后应用；支持重新分析。
- 已有标题若层级合理保持原级；列表/代码块等非文本块不参与转换。
- 应用在**单个事务**内完成，⌘Z 一次整体撤回；应用后 Toast 提示。

### 4.5 顶部工具栏

撤销⌘Z 重做⌘⇧Z(Ctrl+Y) ｜ 样式下拉（显示当前块名：正文/标题1~9渐进） ｜ B I U S 行内代码 ｜ 颜色▾ ｜ 链接⌘K ｜ 评论(占位) ｜ 对齐▾(⌘⇧L/E/R) ｜ 无序⌘⇧8 有序⌘⇧7 任务⌘⌥T ｜ 引用⌘⇧> ｜ 代码块⌘⌥C 分割线⌘⌥S 高亮块 图片 表格▾。**无字号概念，不显示字号。**

### 4.6 块选中与全选

- **Esc** 选中光标所在顶层块（蓝底 `--brand-light`），再按 Esc 取消；编辑/移动光标自动取消。有浮层打开时 Esc 先归浮层。
- **连按 ⌘A**：第一次选当前块内容（原子块选中节点），第二次全选文档。
- Tab/Shift+Tab：列表内 sink/lift；段落/标题增减缩进（0~9 级，24px/级）；代码块内插入两空格。

### 4.7 大纲 / 空态 / 保存 / 分享

- 大纲面板位于**正文左侧** 240px，可收起/展开（§4.3.1）；列出 H1~H9 全量（不受渐进规则限制），点击跳转、当前标题高亮；空态「无标题内容」。
- 空文档正文占位 `输入 / 快速插入内容`；标题占位 `无标题文档`。
- 输入防抖 500ms 自动保存，TopBar 显示「保存中…/已保存」；localStorage 持久化。
- 分享弹层 400px：链接权限、复制链接、协作者占位（权限细分 P2）。
- 阅读模式：隐藏工具栏与把手；按 **E** 返回编辑。
