# 飞书云文档复刻 — 差距分析与全量优化方案

> 状态:**P0~P2 已实施**(2026-09-06,含浏览器验证);P3 除协作预留外待排期。本轮新增:代码块语法高亮/语言搜索/自动换行、表格单元格背景与对齐、图片缩放/对齐/题注/预览/粘贴上传、KaTeX 公式(块+行内)、真实分栏、@提及、日期提醒、本地评论、⌘F 查找替换、历史版本快照、模版面板、文档图标/封面、页面宽度、暗色模式、导出 PDF、Markdown 粘贴转换、IndexedDB 持久化、ESLint+Vitest。多维表格/电子表格按决策暂缓。
> 决策记录(用户确认):
> 1. 「AI帮我写」**接入真实模型**——用户自备 OpenAI 兼容服务(Base URL / API Key / 模型名在面板内配置,存 localStorage,页面直连);
> 2. 块把手/T 按钮**以官方文档为准**(空行行首 `+`;内容块行首 `⋮⋮`,悬停展开 [T 评论 ⋯] 工具条,拖拽移动);
> 3. **多维表格/电子表格暂不做**——斜杠菜单暂不呈现「数据」「多维表格」两组,后续按需补。
>
> 结论先行:当前项目骨架健康(约 4400 行,Tiptap 2 + React 18 + Vite,块模型/工具栏/斜杠菜单的"形"已具备),但**编辑体验的"神"与飞书差距很大**,按模块完整度估算约为飞书的 25%~30%。最核心的问题是:**斜杠菜单结构与飞书完全不符、标题渐进显示规则缺失、飞书四种工具栏体系(+ / ⋮⋮ / 浮动 / 斜杠)只做了一种半**。本文档给出逐项差距、目标规格、分期实施计划,作为后续全量优化的唯一执行依据。

## 3. 两大核心痛点的目标规格(你点名的问题)

### 3.1 斜杠菜单「/ 快速插入」全面重构

**触发条件**:行首输入 `/`,或空格后输入 `/`(当前 Tiptap Suggestion 在任意位置都会触发,需加 `allow` 校验前缀边界)。继续输入做模糊过滤:支持**中文名、英文单词、拼音首字母缩写**(官方缩写表见附录 A,如 `/h1`、`/tp`、`/bg`、`/yy`、`/yxlb`)。

**目标分组与条目**(以你的实机观察为准;标注※的条目文案/图标需在实施时以实机截图二次核对):

**交互细节**:弹层约 340~360px 单列、分组标题置顶吸顶、↑↓ 循环选择、Enter/Tab 插入、Esc 删除 `/query` 并关闭(已实现)、鼠标 hover 同步高亮(已实现)、无结果空态。条目=图标 20px + 名称 + 右侧 12px 灰字说明。

### 3.2 标题渐进显示(飞书的"防滥用层级"设计)

**规则**(已获第三方拆解印证,与你观察一致):

```
可见标题级别 = 1 .. min(9, max(3, 文档中已使用的最深层级 + 1))
```

- 新文档:只显示 一级/二级/三级标题。
- 使用了三级标题后:四级标题出现;使用了四级后:五级出现……直到九级。
- 「文档中已使用的最深层级」从当前文档内容**实时推导**(遍历 heading 节点),无需持久化;删除标题后按剩余内容即时回收。

**生效位置**(四处统一,封装一个 `getVisibleHeadingLevels(doc)` 工具):
1. 斜杠菜单「基础」组;
2. 顶部工具栏"块类型"下拉(同时飞书该下拉显示的是当前样式名);
3. 浮动工具栏 / ⋮⋮ 工具条中的 T 文本样式菜单 —— 注意官方口径:T 菜单固定显示 **正文/一级/二级/三级标题 +「其他标题」**,"其他标题"是一个子菜单(展开四~九级,同样遵循渐进或全量列出,实施时以实机核对);
4. Markdown 输入规则保持 1~9 全量(输入侧不限制,`####` 直接可用)。

### 3.3 块把手与「T」按钮(飞书四种工具栏体系)

官方定义四种工具栏,我们只做了"半种":

| 工具栏 | 飞书行为 | 现状 → 目标 |
|---|---|---|
| `/ 快速插入` | 行首/空格后 `/` 唤起 | 已有 → 按 3.1 重构 |
| `+ 工具栏` | 悬停**空白行**行首出现 `+`,悬停/点击打开插入菜单(条目同斜杠菜单) | 部分有 → 限定空行场景,菜单复用斜杠菜单数据 |
| `⋮⋮ 工具栏` | 悬停**内容块**行首出现 `⋮⋮`;**悬停 ⋮⋮ 展开横向工具条**:T(文本样式菜单)、缩进增减、对齐、评论、剪切/复制等;底部「在下方添加」;**按住 ⋮⋮ 拖拽**移动块(蓝色插入指示线) | 点击弹简单菜单 → 重做为:悬停展开工具条 + 拖拽 |
| `浮动工具栏` | 选中内容后出现在选区上/下方,按钮随内容类型变化 | 部分有 → 补 T 菜单/缩进/评论/合并色板 |

你观察到的"行首 T 按钮":按官方文档应为 ⋮⋮ 悬停展开后的工具条中的 **T 样式按钮**(不同块类型时该位置图标会变化,如列表块显示列表图标)。实施时按此实现,并以你的实机截图校准图标顺序与出现方式(见开放问题 Q2)。

**T 文本样式菜单条目**(官方):正文 / 一级标题 / 二级标题 / 三级标题 / 其他标题(子菜单) / 有序列表 / 无序列表 / 任务 / 代码块 / 引用 / 高亮块 / 同步块。

**⋮⋮ 拖拽实现要点**:mousedown 于把手 → 监听 mousemove 计算目标插入位(块中线判定)→ 渲染水平蓝色指示线(色 `--brand` 2px)→ mouseup 时 `editor.commands.insertContentAt` 移动块 JSON;跨容器(列表项、高亮块内)同样支持。

## 4. 其余模块逐项差距

### 4.1 顶部工具栏(重构)
- 删除静态"16px"字样(飞书文档无字号概念,设计规范 §2 也写明)。
- 结构对齐:`撤销 重做 | 样式(当前块类型名 ▾,渐进) | B I U S 删除线 行内代码 | 字体颜色/背景色(合并面板,A▾+🖍▾ 二合一,含"恢复默认") | 链接 | 评论(占位) | 对齐 | 缩进+/- | 无序 有序 任务 | 引用 | 代码块 | 分割线 | 表格 | 插入更多 ▾(图片/高亮块/公式/分栏…) |`(精确按钮集合以实机截图核对)。
- 快捷键重映射(对照官方表):删除线 ⌘⇧X、行内代码 Win Ctrl+Shift+C/Mac Ctrl+⌘ C、代码块 ⌘⌥C、任务 ⌘⌥T、引用 ⌘⇧>、分割线 ⌘⌥S、正文 ⌘⌥0、标题 ⌘⌥1~3(+4~9 自定义补齐)、字体颜色/背景色 ⌘⌥H、上下移动块 Win Alt+Shift+↑↓ / Mac ⌘⇧↑↓、重做 Win Ctrl+Y。Tooltip 里展示快捷键(官方:悬停可见快捷键)。

### 4.2 编辑行为
- **Tab/Shift+Tab**:列表内 sink/lift(listItem),正文块缩进(飞书缩进适用于标题/段落/列表/图片/表格等,9 层)。
- **Esc 选中整块**:光标所在块进入选中态(蓝底 `--brand-light`),再按 Esc 上移到父块;Shift+↑↓ 跨块扩展选区;连按 ⌘A:第一次选当前块、第二次全选(官方"连按 Ctrl+A"即此意)。
- **Enter/Backspace 边界**:标题行 Backspace 转正文;空列表项 Enter 退出列表(已有部分);空引用/高亮块 Backspace 退出;⇧Enter 块内软换行(需 HardBreak 对齐)。
- **粘贴**:粘贴 Markdown 文本自动转块(P2);粘贴纯 URL 自动生成链接(已有 autolink);粘贴图片上传(已有 Image 但需粘贴事件处理)。
- **查找替换**:⌘F 查找浮层、⌘⇧H 替换(P2,高亮命中+计数)。

### 4.3 块能力补齐(对照官方 block_type 枚举)
- **公式**(equation):行内 + 块级,引入 KaTeX 渲染,`/gs` 唤起,`^`/`_` 上下标。
- **代码块**(code):lowlight 语法高亮、语言下拉带搜索、自动换行开关、复制(已有)。
- **表格**(table):`resizable: true` 列宽拖拽、选中单元格时顶部/左侧 `+` 插入行列、单元格背景色/对齐、表头行开关、删除行列菜单(部分已有)。
- **图片**(image):NodeView 增强——拖角缩放(按住等比)、对齐(左/中/右)、题注、点击全屏预览(缩放/下载/关闭)、粘贴/拖拽上传、加载失败态。
- **引用容器**(quote_container):飞书"引用"可包含多个块(当前 Tiptap blockquote 已是 block+,验证多块/嵌套列表行为即可)。
- **分栏**(grid/grid_column):两栏/三栏/左窄右宽/右窄左宽布局,栏内可嵌任意块。
- **同步块**:创建后可"复制到其他文档",本档 Mock。
- **重块 Mock 卡片**:电子表格(sheet)、多维表格及四种视图(bitable)、画板/流程图/思维笔记(diagram/mindnote)、投票、群名片、信息收集、日程/会议议程——统一做成"类型图标+名称+空态提示"的卡片块,视觉对齐飞书占位风格。
- **人员(@提及)**:`@` 唤起成员浮层(M ack 用户列表),插入高亮 mention 标记。
- **日期提醒**:`/rq` 或 `//` → 日期选择浮层 → 插入蓝色日期 chip。

### 4.4 页面级
- **文档图标与封面**:标题上方圆形 emoji 图标(hover 更换),顶部封面横幅(hover "添加封面",内置渐变/纯色候选)。
- **面包屑**:TopBar 返回键旁显示 `云文档 / 文档名`。
- **目录面板**:官方《设置文档章节标题与目录》口径为目录"固定展示在正文左侧"、可开关;当前在右侧且无开关按钮——TopBar「⋯」菜单已有开关,补充:目录按钮形态/左右位置以实机核对后定稿;当前可视标题高亮已有。
- **阅读模式**:隐藏工具栏/把手;右下角悬浮「编辑」按钮(官方快捷键表:阅读模式按 E 进入编辑——做该快捷键)。
- **字数统计**:「⋯」菜单显示文档字数/创建/修改时间。
- **分享弹层细化**:链接权限(组织内可阅读/可编辑等)、有效期、禁用复制/下载/打印开关(Mock)。
- **历史记录**:本地每次保存留存快照(最近 N 版),版本列表+预览+回滚(真实现,成本可控)。
- **首页**:新建按钮下拉(文档/电子表格/多维表格/思维笔记→均以文档打开)、主页"最近访问"区、文件夹树(我的空间,可建文件夹)、导入(Markdown/HTML→文档)。

### 4.5 工程质量(伴随每期做)
- **渲染性能**:工具栏/浮条当前监听 `transaction` 全量 force-update → 改用 `useEditorState` 精确订阅;BlockHandle mousemove 全量遍历 `children` + N 次 `getBoundingClientRect` → rAF 节流 + 缓存块矩形,doc 变更时失效。
- **去重**:`Dropdown.tsx` 与 `ToolbarBtns.tsx` 各有一份 `MenuItem`;`palettes.ts` 与 `CalloutView` 的 CALLOUT_COLORS 重复 → 单一数据源。
- **持久化**:localStorage 5MB 限制,图片 base64 极易撑爆 → 改 IndexedDB(内容与元数据分库),加 schema 版本号与迁移函数;提供 JSON 导入/导出。
- **类型与规范**:消除 `any`(BlockHandle 大量 any)、补 ESLint + Prettier;关键交互加 Vitest 冒烟测试(渐进标题/斜杠过滤/输入规则)。
- **验收文档**:实施第一步把 `docs/design-spec.md` 升级为 v2(以本方案为准重写第 3/4 章),保持"唯一验收依据"的地位。
